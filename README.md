# JobHunter

Autonomous job discovery agent that runs twice daily, scrapes 8+ sources, scores jobs by salary / visa sponsorship / title match, and writes prioritized results to a Google Sheet with AI-generated outreach drafts.

**Sources:** Greenhouse API · Lever API · Ashby API · Company-direct Playwright · Remotive · Himalayas

**Scoring:** 0–100 with priority tiers 🔴(70+) 🟡(50–69) 🟢(30–49) ⚪(<30)

---

## Setup (30 min)

### Prerequisites
- Python 3.11+
- [Railway](https://railway.app) account (free tier works)
- Google Cloud account (free)
- [Supabase](https://supabase.com) account (free tier works)
- Anthropic API key ([console.anthropic.com](https://console.anthropic.com))

---

### Step 1 — Clone & configure

```bash
git clone https://github.com/your-username/job-hunter.git
cd job-hunter
cp .env.example .env
```

Fill in `.env` — instructions for each value are in the file.

---

### Step 2 — Google OAuth (for Google Sheets)

1. Go to [console.cloud.google.com](https://console.cloud.google.com) → create a new project
2. Enable **Google Sheets API** and **Google Drive API**
3. Go to **APIs & Services → OAuth consent screen** → External → add your email as a test user
4. Go to **Credentials → Create Credentials → OAuth client ID → Desktop app** → download the JSON
5. Rename the file to `client_secret.json` and place it in the project root (it's gitignored)
6. Run the auth flow once to generate a refresh token:

```bash
python auth_google.py
```

Copy the printed `GOOGLE_REFRESH_TOKEN` into your `.env`.

---

### Step 3 — Supabase

1. Create a new project at [supabase.com](https://supabase.com)
2. Go to **Settings → API** and copy the URL and secret key into `.env`
3. Go to **SQL Editor** and run the schema from the docstring in `tools/supabase_store.py`

---

### Step 4 — Google Sheet

```bash
python setup_sheet.py
```

This creates all tabs (Job Tracker, Company List, Role Title Config, Run Log) and populates the default company list and titles. Copy the printed Sheet ID into your `.env` as `GOOGLE_SHEET_ID`.

---

### Step 5 — Customize

Open your Google Sheet:

- **Company List tab**: add/remove companies. Columns: `Company Name`, `Domain`, `Careers Page URL` (optional — auto-discovered)
- **Role Title Config tab**: edit target job titles to match your search
- Salary threshold and scoring weights are in `config/settings.py`

---

### Step 6 — Deploy to Railway

1. Push the repo to GitHub
2. Create a new Railway project → **Deploy from GitHub repo**
3. Add all variables from your `.env` as Railway environment variables
4. Railway auto-detects the `Dockerfile` and deploys

The scheduler runs at **6 AM and 1 PM PT** by default (configurable in `config/settings.py`).

---

### Step 7 — Manual trigger

```bash
# Local
python main.py --run-now

# Railway CLI
railway run python main.py --run-now
```

## Architecture

```
main.py (scheduler + health check)
├── crews/discovery_crew.py   — scrapes all sources
├── crews/enrichment_crew.py  — scores + visa filters
├── crews/linkedin_crew.py    — AI outreach drafts
└── crews/output_crew.py      — dedup + write to sheet

tools/scrapers/
├── greenhouse.py             — Greenhouse API
├── lever.py                  — Lever API
├── ashby.py                  — Ashby API
├── company_direct.py         — Playwright (with auto URL discovery)
├── remotive.py               — Remotive job board API
└── himalayas.py              — Himalayas job board API

tools/
├── scoring.py                — 0–100 score + priority tier
├── visa_check.py             — H1B keyword + database lookup
├── h1b_lookup.py             — h1bdata.info + myvisajobs.com
└── sheets.py                 — Google Sheets read/write
```

## Environment Variables

| Variable | Description |
|---|---|
| `ANTHROPIC_API_KEY` | Anthropic API key for outreach drafts |
| `GOOGLE_SHEET_ID` | ID from your Google Sheet URL |
| `GOOGLE_CLIENT_ID` | OAuth client ID |
| `GOOGLE_CLIENT_SECRET` | OAuth client secret |
| `GOOGLE_REFRESH_TOKEN` | Generated by `python auth_google.py` |
| `SUPABASE_URL` | Your Supabase project URL |
| `SUPABASE_KEY` | Supabase secret key |
| `LINKEDIN_COOKIE_LI_AT` | Optional — LinkedIn session cookie |
